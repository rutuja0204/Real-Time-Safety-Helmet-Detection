# 🦺 Real-Time Industrial Safety Helmet Detection

## 📌 Overview

The **Real-Time Industrial Safety Helmet Detection System** is an AI-powered web application that detects whether workers are wearing safety helmets using the YOLOv8 object detection model. The system processes uploaded videos and identifies workers with and without helmets to improve industrial safety compliance.

This project demonstrates practical applications of Computer Vision and Deep Learning in workplace safety monitoring.

---

## ✨ Features

- Real-time helmet detection using YOLOv8
- Detects Helmet and No-Helmet classes
- Upload video for analysis
- Bounding boxes with confidence scores
- Web interface using Flask
- Fast inference with OpenCV
- Industrial safety monitoring application

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Real-Time-Safety-Helmet-Detection.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
